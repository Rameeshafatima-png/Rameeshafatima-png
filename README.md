### 🧠 Featured Work

Three projects I'm most proud of. Click a card to see what's inside.

</div>

<details>
<summary><b>📄 PaperMind AI</b> · Research Paper Assistant (RAG)</summary>

<br>

Upload research papers and ask questions in plain language.

- Extracts text page by page and chunks it for retrieval
- Stores embeddings in a **FAISS** index
- **Google Gemini** answers using only the retrieved context
- Every answer cites the **source document, page number and similarity score**

**Stack:** `Python` `FastAPI` `Gemini` `FAISS` `PyMuPDF` · [View repo](https://github.com/Rameeshafatima-png/PaperMind-AI)

</details>

<details>
<summary><b>🖼️ CIFAR-10 Image Classifier</b> · Deep Learning + Deployment</summary>

<br>

A complete image classification pipeline, from preprocessing to deployment.

- Preprocessing and **CNN** training with TensorFlow / Keras
- Evaluation across the 10 CIFAR-10 classes
- **FastAPI** web interface returns the predicted class and confidence in real time

**Stack:** `Python` `TensorFlow` `Keras` `FastAPI` `Matplotlib` · [View repo](https://github.com/Rameeshafatima-png/CIFAR10-_Image_Classification)

</details>

<details>
<summary><b>✉️ AI Email Generator (Dispatch)</b> · Generative AI Web App</summary>

<br>

Writes complete, polished emails from a recipient, a purpose and a tone.

- Tones: **Professional, Friendly or Formal**
- **Gemini** generates the body and an automatic subject line
- **FastAPI** backend with **Pydantic** validation, a health-check endpoint and error handling

**Stack:** `Python` `FastAPI` `Gemini` `Pydantic` `JavaScript` · [View repo](https://github.com/Rameeshafatima-png/AI_Email_Generator)

</details>

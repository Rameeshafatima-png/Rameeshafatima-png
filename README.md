## Featured Projects

### PaperMind AI — Research Paper Assistant

**RAG-based AI application** that allows users to upload research papers and ask questions using natural language.

The system extracts and processes PDF content, creates embeddings, stores them in a FAISS index, and uses Google Gemini to generate grounded responses based on retrieved document context.

**Technologies:** Python · FastAPI · Google Gemini · FAISS · PyMuPDF

[View Project](https://github.com/Rameeshafatima-png/PaperMind-AI)

---

### CIFAR-10 Image Classification

A deep learning image classification project using **TensorFlow and Keras**. The project includes preprocessing, CNN training, evaluation, visualization, and deployment through FastAPI.

Users can upload an image through a web interface and receive the predicted class with a confidence score.

**Technologies:** Python · TensorFlow · Keras · FastAPI · Matplotlib

[View Project](https://github.com/Rameeshafatima-png/CIFAR10-_Image_Classification)

---

### AI Email Generator

A Generative AI web application that creates professional emails based on the recipient, purpose, and selected writing tone.

The application uses a FastAPI backend, Pydantic validation, Google Gemini, and JavaScript for the frontend.

**Technologies:** Python · FastAPI · Google Gemini · Pydantic · JavaScript

[View Project](https://github.com/Rameeshafatima-png/AI_Email_Generator)

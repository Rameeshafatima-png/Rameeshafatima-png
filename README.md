###  [PaperMind AI](https://github.com/Rameeshafatima-png/PaperMind-AI) &nbsp;·&nbsp; Research Paper Assistant (RAG)

Upload research paper PDFs and ask questions in plain language. PaperMind AI extracts text page by page, chunks it, creates embeddings, and stores them in a **FAISS** index. Questions are answered by **Google Gemini** using only the retrieved paper context, and every answer comes with the **source document, page number and similarity score**, so it stays grounded and verifiable.

###  [CIFAR-10 Image Classification](https://github.com/Rameeshafatima-png/CIFAR10-_Image_Classification) &nbsp;·&nbsp; Deep Learning + Deployment

A complete image classification workflow: data preprocessing, **CNN** training and evaluation with TensorFlow/Keras, then deployment through **FastAPI**. Users upload an image in a modern web interface and get a **predicted class with a confidence score** in real time, across the 10 CIFAR-10 categories.
